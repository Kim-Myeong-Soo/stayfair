TL;DR  Raising the guidance scale quietly changes who a diffusion model draws. We show this guidance bias is separate from the model's own bias, and fix it by changing only the guidance step. No retraining and no attribute labels at inference.

Abstract

Diffusion models steer conditional generation with a tunable guidance scale to trade off prompt alignment and diversity. However, existing debiasing techniques are optimized for a single scale, degrading fairness when users adjust this parameter. We trace this behavior to a previously overlooked source by decomposing total bias into two components: a model bias and a guidance bias. While prior work primarily targets the former, we show that the guidance bias varies with the guidance scale, persisting even in models that have already been debiased.

To address this, we extend Strong Demographic Parity to guidance and derive a condition under which the target distribution retains its group ratio across guidance scales. Building on this condition, we propose StayFair, which designs fair guidance algorithms in both regimes. For classifier guidance, it equalizes the classifier's output distributions across groups; for classifier-free guidance, it shifts the null embedding by a prompt-dependent offset. Because StayFair modifies only the guidance step, it is orthogonal to model debiasing and can be layered onto existing fair diffusion models. Across class-conditional and text-to-image generation, StayFair decouples fairness from the guidance scale without sacrificing image quality. Our decomposition also enables a more detailed analysis of the sources of bias in diffusion models.

Guidance creates its own bias

Guidance samples from $p^w_\theta(x_t\mid y)\propto p_\theta(x_t)\,p_\theta(y\mid x_t)^w$, where the user-chosen scale $w$ sets how strongly the condition $y$ is followed. A higher $w$ amplifies not only the condition but also the social bias it carries, so the generated group distribution $Q^w(a\mid y)$ drifts as $w$ changes. We separate the total bias from a target $T(a\mid y)$ into two parts:

$$\underbrace{Q^w(a\mid y)-T(a\mid y)}_{\text{Total bias}} \;=\; \underbrace{Q^w(a\mid y)-Q^{w_{\mathrm{ref}}}(a\mid y)}_{\text{Guidance bias } \mathrm{Bias}_{\mathrm{G}}^w} \;+\; \underbrace{Q^{w_{\mathrm{ref}}}(a\mid y)-T(a\mid y)}_{\text{Model bias } \mathrm{Bias}_{\mathrm{M}}}$$

Prior work targets model bias at a single scale. Guidance bias is what changes when the user moves the slider. It appears in two places:

  • Vanilla models: guidance pushes the data distribution toward the majority group, more strongly as $w$ grows.
  • Debiased models: a model fitted to be fair at $w_{\mathrm{ref}}$ drifts away from its target once $w\neq w_{\mathrm{ref}}$. This holds even when debiasing is fitted across a range of scales.

We therefore ask for fair guidance: $\mathrm{Bias}_{\mathrm{G}}^w(a\mid y)=0$ for every $w\in[w_{\min},w_{\max}]$. The group distribution should not depend on the scale.

StayFair: fair guidance across scales

Overview of StayFair. (a) In classifier guidance, StayFair adds the fairness constraint $\mathcal{L}_{\mathrm{WDP}}$ when training the classifier $f_\phi$, aligning its output distribution across groups. (b) In classifier-free guidance, StayFair replaces the fixed null prompt $\varnothing$ with an adaptive $\varnothing_y$, shifting its embedding along the attribute direction.

A sufficient condition

Because $p^w_t(\cdot\mid y)\propto p^0_t(\cdot\mid y)\,f(\cdot,t)^w$, any group-dependent bias in the guidance function $f$ is raised to the power $w$. We extend Strong Demographic Parity (SDP) to $f$: the law of $f(X_t,t)$ must be the same for every group.

Theorem 1 (SDP preserves fairness in the target distribution). If $f(\cdot,t)$ satisfies SDP, then for every $w\ge 0$ and groups $a,a'$, $$\frac{p^w_t(a\mid y)}{p^w_t(a'\mid y)}=\frac{p^0_t(a\mid y)}{p^0_t(a'\mid y)}.$$ The group ratio stays the same at every guidance scale.

Theorem 2 shows that, in a Gaussian setting, SDP also carries over to the distribution actually sampled, giving $\mathrm{Bias}_{\mathrm{G}}^w=0$ for all $w$.

Classifier guidance: equalize the classifier

We train the classifier with an added Wasserstein Demographic Parity loss. Classifier outputs of different groups are matched through an optimal transport plan whose cost also accounts for the noise level:

$$\mathcal{L}=\mathcal{L}_{\mathrm{CE}}+\lambda\sum_{a,a'}\mathcal{L}_{\mathrm{WDP}}(a,a')$$

Classifier-free guidance: an adaptive null prompt

In CFG, $f$ is only implicit, so we change the branch it is measured against. We shift the null embedding along the attribute direction by a prompt-dependent amount $\alpha(y)$:

$$E(\varnothing_y) = E(\varnothing) + \alpha(y)\,\frac{E(a^+)-E(a^-)}{\lVert E(a^+)-E(a^-)\rVert}, \qquad \nabla\log f = \nabla\log p_\theta(x_t\mid y)-\nabla\log p_\theta(x_t\mid\varnothing_y)$$

StayFair (Search) finds $\alpha(y)$ by binary search so the group ratios at the lowest and highest scales match. StayFair (Estimate) looks $\alpha(y)$ up from a table of earlier searches, using group ratios from a few generated images. Because only the guidance step changes, StayFair can be layered on any debiased model:

$$\epsilon^{\text{StayFair}}=\epsilon^{\text{Fair}}+(w-w_{\mathrm{ref}})\bigl(\epsilon_\theta(x_t,y)-\epsilon_\theta(x_t,\varnothing_y)\bigr)$$

Analysis: Guidance bias explains asymmetric amplification

Recent text-to-image models over-represent the majority gender relative to workforce ratios more often when that majority is male than when it is female. Separating guidance bias from total bias reveals an overlooked source of this asymmetry.

Guidance amplifies male bias more strongly in recent T2I diffusion models. Each point is an occupation–template pair; its deviation from $y=x$ reflects guidance bias across scales. Points and fitted curves deviate more from $y=x$ below each fitted crossing than above it, indicating stronger guidance bias toward men than toward women.

We attribute this asymmetry to a female bias in the null branch $p_\theta(\cdot\mid\varnothing)$, indicated by fitted crossings with $y=x$ above 0.5 (SD3: 0.63, FLUX.2: 0.66). Because CFG subtracts the null branch, this female bias offsets the female bias in the guidance function $f$, so male bias is amplified more strongly even for comparably biased occupation prompts. Shifting $\varnothing$ toward male reduces the asymmetry and moves the crossings toward 0.5. These findings call for finer-grained fairness evaluation that distinguishes guidance bias within total bias.

Scope and limitations

  • For CFG, StayFair reduces group bias in the implicit guidance function; it does not exactly enforce SDP.
  • $\alpha(y)$ is set from group ratios measured by a predictor, so errors in that predictor can carry over.
  • StayFair targets guidance bias only. It does not remove the model's own bias; combine it with a debiased model for that.
  • Our main analysis covers binary gender, with a supplementary race analysis. Other attributes remain future work.
